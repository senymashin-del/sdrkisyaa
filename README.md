# Сайт-поздравление для Киси

Этот набор файлов — персональный сайт-поздравление ко дню рождения. Включает страницы:
- `index.html` — главная страница с поздравлением и фейерверком
- `gallery.html` — фотогалерея
- `wishes.html` — пожелания (сохраняются в localStorage)
- `memories.html` — лента воспоминаний и сюрприз
- `games.html` — мини-игра "Найди пары"
- `music.html` — плеер с визуализатором
- `surprises.html` — интерактивные сюрпризы
- `confessions.html` — признания любви

Файл стилей: `style.css` (используется всеми страницами).

Как настроить:
- Замените заглушки в `gallery.html` на свои фото (замените ссылки `https://picsum.photos/...`).
- В `music.html` можно заменить `audio src` на локальные файлы (положите mp3 в папку проекта).
- В `index.html` укажите дату дня рождения в теге `<body data-birthday="MM-DD">` (например `data-birthday="04-12"`).
- Персонализируйте тексты — ищите слова "Кися" и заменяйте по желанию.

Примечание: сайт полностью статический и работает локально в браузере. Я добавил компактные геро‑блоки на основные страницы и кнопку «Наверх» с клавиатурной доступностью, чтобы перемещаться по сайту было удобнее. Если хотите, могу помочь добавить дополнительные страницы, анимации или экспорт в GitHub Pages.
